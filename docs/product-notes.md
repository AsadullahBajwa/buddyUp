# BuddyUp Product Notes

## App Icon Directions

- Orange buddy-smile mark on a black-blue background.
- Two abstract people forming an upward arrow.
- Flame plus chat bubble mark for streak-based accountability.

## App Store Screenshot Set

1. Onboarding: "Find your accountability partner."
2. Discover: "Swipe into serious goal matches."
3. Check-in: "Share daily progress and keep streaks alive."
4. Chat: "Stay accountable with real conversations."
5. Dashboard: "Track goals, XP, badges, and reliability."
6. Community: "Join focused groups and challenges."

## Initial Production Milestones

1. Replace mock data with Firebase Auth and Firestore reads.
2. Add image and voice upload flows with Firebase Storage.
3. Add push notification permissions and missed check-in reminders.
4. Add swipe gestures and animated card transitions.
5. Add AI coach endpoint backed by Cloud Functions.
6. Add moderation, reporting, blocking, and community safety screens.
